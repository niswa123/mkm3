# ⚛️ 3D Физическая Лаборатория: Математический Маятник

Интерактивная 3D-лаборатория и платформа численного анализа колебаний математического маятника. Проект разработан на основе учебного пособия **«Компьютерное моделирование физических процессов» (2024)** и реализует четыре расчетные работы.

Приложение разработано полностью вручную на **TypeScript, WebGL (Three.js) и Canvas API** без использования готовых игровых движков (Unity, Unreal, Godot).

---

## 🔬 Реализованные проекты из методички

1. **Проект 1.9: Колебания на малых и больших углах**
   * Сравнение периода по формуле Гюйгенса (для малых углов) и точного значения через эллиптический интеграл первого рода $K(k)$ (по полиномиальному разложению из методички).
   * Вычисление численного периода колебаний в симуляции методом **линейной интерполяции засечек положения равновесия** (пересечение $\varphi=0$, стр. 41).
2. **Проект 1.11: Затухающие колебания**
   * Моделирование сопротивления среды (линейного и квадратичного) с автоматическим построением фазового портрета колебаний $(\varphi, \dot{\varphi})$ в виде логарифмической спирали.
3. **Проект 1.12: Численная модель маятника Фуко в 3D**
   * Решение полных трехмерных уравнений движения с учетом **силы Кориолиса** $2(\vec{v} \times \vec{\omega}_{\text{earth}})$ и переменной силы натяжения нити $N$.
   * Отрисовка траектории движения на полу в виде канонической круговой **розы/розетки**.
4. **Проект 1.15: Параметрический резонанс**
   * Вертикальная гармоническая раскачка точки подвеса с частотой $\omega \approx 2\omega_0$, приводящая к экспоненциальному росту амплитуды колебаний из сверхмалого угла ($0.1^\circ$).

## 🛠️ Архитектура и структура кода

Код организован по паттерну MVC (Model-View-Controller) и разбит на независимые модули в папке `src/`:
* [physics.ts](file:///Users/ape.ces/Desktop/mkmk3/src/physics.ts) — **Физическое ядро (Model)**. Реализует структуру `Vector3D` и численные интеграторы: **алгоритм Верле** (сохраняющий энергию), **Эйлера-Кромера** и **Рунге-Кутты 4-го порядка (RK4)**.
* [visualizer.ts](file:///Users/ape.ces/Desktop/mkmk3/src/visualizer.ts) — **3D Визуализатор (View)**. Рендерит маятник на Three.js, строит шлейф траектории, сетку компаса и **3D-векторы сил** (Сила тяжести — зеленый, Натяжение — синий, Кориолис — красный). Управление камерой (мышкой и зумом) также написано вручную.
* [charts.ts](file:///Users/ape.ces/Desktop/mkmk3/src/charts.ts) — **Двумерные графики (View)**. Сверхбыстрый рендеринг графиков времени (координата, скорость, энергия) и фазовых плоскостей на чистом Canvas API (60 FPS).
* [ui.ts](file:///Users/ape.ces/Desktop/mkmk3/src/ui.ts) — **Контроллер интерфейса (Controller)**. Управляет вкладками, синхронизирует ползунки с параметрами и рендерит динамические формулы.
* [main.ts](file:///Users/ape.ces/Desktop/mkmk3/src/main.ts) — **Координатор приложения**. Управляет игровым циклом (`requestAnimationFrame`), временным шагом (substepping) и фиксирует моменты засечек периода.

## 🚀 Инструкция по запуску

Для работы проекта требуется установленная среда **Node.js** (версии 18+).

### 1. Установка зависимостей
Откройте терминал в папке проекта и установите пакеты (Vite, TypeScript, Three.js):
```bash
npm install
```

### 2. Запуск в режиме разработки
Запустите сервер горячей перезагрузки:
```bash
npm run dev
```
После запуска в терминале появится ссылка (по умолчанию **`http://localhost:5173/`**). Откройте её в любом браузере. Любые изменения в коде будут мгновенно отображаться на экране.

## 📦 Сборка для сдачи работы (Автономный режим)

Чтобы сдать проект преподавателю без необходимости запуска сервера разработки Node.js, соберите оптимизированный продакшн-пакет:
```bash
npm run build
```
Эта команда создаст папку **`dist`** в корне проекта:
* Папка содержит скомпилированный, сжатый и полностью самодостаточный код (файл `index.html` и папка `assets` со стилями и скриптами).
* **Для запуска достаточно заархивировать папку `dist` и сдать преподавателю.** Ему нужно будет лишь распаковать архив и дважды кликнуть на `index.html` — всё мгновенно запустится на любом компьютере прямо в браузере в режиме оффлайн!
